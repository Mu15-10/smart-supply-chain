# Smart Supply Chain Dashboard

واجهة ويب عربية متجاوبة لإدارة سلسلة التوريد، مبنية بـ React وVite. تحتوي على لوحة التشغيل، الموردين، المنتجات، المستودعات، المخزون وأوامر الشراء، وتعمل حاليًا ببيانات تجريبية واضحة.

## التشغيل

```bash
npm install
npm run dev
```

لإنشاء نسخة الإنتاج:

```bash
npm run build
```

المستودع المقابل للـBackend هو:
`https://github.com/Mu15-10/smart-supply-chain-backend`
