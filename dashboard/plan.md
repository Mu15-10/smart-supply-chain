# خطة تحسين لوحة سلسلة التوريد — 011 + Impeccable

## الفهم والافتراضات

الهدف هو تحسين واجهة تشغيل عربية RTL موجودة، لا تغيير وظائفها أو عقودها. المستخدم الأساسي مدير العمليات وموظف المشتريات والمخزون؛ لذلك الأولوية للقراءة السريعة، معرفة حالة النظام، وإنجاز أمر شراء أو معالجة تنبيه مخزون بأقل تردد. البيانات الحالية تجريبية ومعلّمة بذلك، ولا نضيف ادعاءات تشغيلية جديدة.

## الاتجاه البصري

اعتماد عالم Impeccable «Paper and Instruments» داخل سياق سلسلة التوريد: أسطح ورقية محايدة، حبر أخضر-أسود للعناوين، patina للحالة الطبيعية، ذهب كعلامة تركيز صغيرة، وvermilion للفشل/الخطر فقط. نزيل الخلفيات الداكنة والزخرفة غير الضرورية، ونستخدم العمق فقط للأدوات القابلة للتفاعل.

## مخطط التدفق

المستخدم يفتح لوحة التشغيل → يرى حالة النظام والتنبيهات قبل الأرقام الثانوية → ينتقل إلى المخزون أو أوامر الشراء من إجراءات مباشرة → يستخدم جدولًا قابلًا للبحث → ينفذ نموذجًا صغيرًا → يحصل على تأكيد واضح. في الهاتف تنكمش الملاحة إلى زر، وتبقى التنبيهات وأمر الشراء في أعلى التسلسل.

## مراحل التنفيذ

1. **تشخيص:** تشغيل detector، مراجعة hierarchy، التباين، touch targets، overflow، copy، والحالات.
2. **نظام بصري:** تحويل الألوان والمسافات والظلال والأحجام إلى tokens؛ ضبط الخط العربي وتسلسل العناوين؛ توثيق DESIGN.md.
3. **تنفيذ الواجهة:** إعادة بناء الشريط الجانبي/الرأس، hero، المؤشرات، الجداول، الحالات، والنماذج دون كسر السلوك الحالي.
4. **تقوية:** إضافة reduced-motion، تحسين التركيز ولوحات المفاتيح، حالات empty/loading/error، وأسماء أوضح للأزرار.
5. **تحقق:** build، detector، لقطة سطح المكتب والجوال، مراجعة diff، ثم push للمستودع.

## الأمان والاعتمادية

لا توجد أسرار أو اتصالات خارجية في الواجهة. كل البيانات illustrative. لا نغير الـAPI أو التخزين. لا نضمّن node_modules أو dist في GitHub.

## معايير القبول

- الاتجاه RTL واضح على سطح المكتب والجوال.
- وظيفة التنقل والنماذج والبحث كما هي.
- المسار الأساسي: تنبيه مخزون → صفحة المخزون أو أمر شراء جديد واضح خلال نظرة واحدة.
- التباين والتركيز ولوحات المفاتيح قابلة للاستخدام.
- لا يوجد overflow أفقي غير مقصود على 375px.
- build ناجح وdetector findings مبررة أو معالجة.
