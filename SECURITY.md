# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Report them privately through the repository owner's GitHub contact channel, including a description, reproduction steps, affected commit, and potential impact. Do not include production secrets or personal data.

The project is an evolving MVP. A report is acknowledged when it can be reproduced; remediation timelines depend on severity and available deployment evidence. Security fixes are developed on a dedicated branch and validated with automated tests before release.
